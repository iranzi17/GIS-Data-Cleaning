# GIS Data Cleaning

A GIS data-preparation project focused on cleaning, structuring, and improving spatial and attribute datasets before mapping, analysis, reporting, or database integration.

## Overview

GIS Data Cleaning supports the practical work required before geospatial data can be trusted. The project is especially relevant for infrastructure and utility workflows where field data, Excel files, shapefiles, GeoPackages, and asset records often require standardization before they can be used in QGIS, ArcGIS, dashboards, or technical reports.

## Problem addressed

Raw GIS data is often affected by:

- inconsistent attribute names
- missing or duplicated records
- poorly formatted coordinates
- mixed naming conventions
- invalid or incomplete geometries
- field-data errors from surveys or site reports
- datasets that are difficult to join, filter, or map

This project focuses on preparing those datasets so they are easier to analyze, visualize, and share.

## Typical use cases

- Cleaning infrastructure asset inventories
- Preparing MV/LV distribution mapping data
- Standardizing field-survey records
- Structuring Excel or CSV data for GIS import
- Supporting spatial joins and attribute joins
- Preparing clean datasets for QGIS, ArcGIS, GeoPackage, or reporting workflows
